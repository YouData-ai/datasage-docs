### MySQL Database Connection

This Document provides instructions to set up a connection between a MySQL database and DataSage.Ai.

![Mysql UI](/images/mysql.png)

###  Connect a Source: MySQL

To connect your MySQL database to DataSage.Ai, follow the steps on the [MySQL connection page](https://datasage-new.youdata.ai/connection/new/my-sql).

---

###  Required Fields

Fill in the following fields on the connection form:

| Field           | Description                                                                 |
|------------------|-----------------------------------------------------------------------------|
| **Name**         | A custom name for your connection. Example: `MyApp_MySQL_DB`               |
| **Description**  | (Optional) A short summary of the database's purpose.                      |
| **Host**         | Hostname or IP address of your MySQL server. Example: `127.0.0.1`          |
| **Port**         | The port number for MySQL (Default: `3306`)                                |
| **Database**     | Name of your MySQL database. Example: `user_data`                          |
| **Username**     | MySQL user with access privileges to the database.                         |
| **Password**     | Password for the specified MySQL user.                                     |

---

###  Common Errors and Fixes

-  **"Please input the Username!"** – The username field is mandatory.
-  **"Please input the Password!"** – You must enter the password to proceed.
-  **Connection Timeout** – Check firewall rules, IP whitelisting, or port blocking.
-  **Access Denied** – Verify that your user has proper permissions for the target database.
