# File

###  File Upload Connection Documentation

This guide explains how to upload and connect to a data file source (such as CSV, Excel, JSON, XML, or PDF) on the DataSage platform.

---

###  Connection Path
`Connection > New source > File`

---

###  Required Fields

| Field             | Description                                                                 |
|-------------------|-----------------------------------------------------------------------------|
| **Name**          | Provide a name for your file source (e.g., `SalesData2024`)                |
| **Description**   | Optional. Enter a brief description about the file and its contents        |
| **Upload File**   | Required. Upload the data file (e.g., `.csv`, `.xlsx`, `.json`, `.xml`, `.pdf`) |

---

###  Supported File Formats

- Comma Separated Values (`.csv`)
- Microsoft Excel (`.xls`, `.xlsx`)
- JavaScript Object Notation (`.json`)
- Extensible Markup Language (`.xml`)
- Portable Document Format (`.pdf`)

>  Only one file can be uploaded per connection.

---

###  Steps to Connect

1. Navigate to the **Connection** section from the sidebar.
2. Select **New Connection** and choose **File**.
3. Fill in the following:
   - **Name**
   - **Description** (optional)
   - **Upload File** by dragging or clicking the file area.
4. Click **Create** to complete the connection.

---

** Notes**

- Ensure that your file is correctly formatted and supported.
- Large files may take longer to upload and process.
- Metadata extraction may vary depending on file type.
