# MSSQL

### Microsoft SQL Server (MSSQL) Connection — DataSage.Ai

This Documentation provides a step-by-step guide to configure and connect a Microsoft SQL Server (MSSQL) data source using the DataSage.Ai platform.

---

###  How to Connect to MSSQL

1. **Navigate to:**  
   `https://datasage-new.youdata.ai/connection/new/ms-sql`

2. **Fill in the required fields:**

###  Connection Configuration Fields

| Field Name       | Description                                             | Example                    |
|------------------|---------------------------------------------------------|----------------------------|
| **Name**         | A unique name for your connection                       | `mssql_production`         |
| **Description**  | Optional description about the data source              | `Production DB for sales`  |
| **Host**         | The hostname or IP address of the SQL Server            | `192.168.1.10` or `db.yourdomain.com` |
| **Port**         | Port number used by MSSQL (default is `1433`)           | `1433`                     |
| **Database**     | Name of the target database within the server           | `SalesDB`                  |
| **Username**     | SQL Server username (SQL authentication only)           | `admin_user`               |
| **Password**     | Corresponding password for the above user               | `yourStrongPassword!123`   |


---

##  Troubleshooting

-  **"Please input the Username!"** – Ensure you fill in the Username field.
-  **"Please input the Password!"** – Enter the correct password before saving.
-  **Security Tip:** Avoid sharing credentials in plain text. Use environment variables or secure vaults for production.

---

**Notes**
- Make sure your MS SQL server allows remote connections.
- If using a cloud database, ensure IP whitelisting is configured to allow connections from DataSage.ai.
